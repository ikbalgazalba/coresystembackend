# Unit U-012 — GL transaction-type link + number-format config (E36/E38)

## Goal

Implement `map_transaction_type_gl` (CoA `[LOCKED]` zero-diff, maker-checker, no delete — E36) + `cfg_number_format` (CREDIT_ID code_type `[LOCKED]`, counter→DB sequence, consumer BE-01 — E38). `CREDIT_ID` code_type change → maker-checker. Number generator service internal (not public endpoint).

## Context

- **Vault source:** `03-data-model.md §Master operasional lain (Tier A)` (GL_TRANSACTION_TYPE_LINK, NUMBER_FORMAT); `04-flows.md F-U-006` (E36/E38); `constitution §I-009` (cfg_number_format + DB sequence, CREDIT_ID change→maker-checker); `06-constraints.md BR-BE07-24`; `05-decisions.md D-MD-05`
- **Binding refs:** C-06 (GL mapping NEW), C-07 (numbering config NEW), C-12 (E29-E38 — this unit E36/E38), C-16 (transaction_type external-FK LOCKED), OQ-GT-02 (credit_id format RESOLVED `branch(5)+YY+MM+SEQ(5)` — consumer BE-01)
- **Why this scope:** BE-07 §10 urutan (5). `map_transaction_type_gl` = CoA `[LOCKED]` zero-diff (read finance/05 + engine disbursement-subledger). `cfg_number_format` = consumer BE-01 mint `credit_id` STEP 8 (OQ-GT-02 ✅). Both maker-checker WAJIB (BR-BE07-05).

## Implementation steps

1. `GlTransactionTypeLink.java` `@Entity @Table(name="map_transaction_type_gl")` extends `VersionedEntity`. Fields BE-07 §3.4: `trxId` (FK → TransactionType), `classId`, `glAccountNo`. Key `ux_..._trx_id_class_id`. `[LOCKED]` CoA zero-diff. (kelas `map_` — bridge).
2. `NumberFormat.java` `@Entity @Table(name="cfg_number_format")` extends `VersionedEntity`. Fields BE-07 §3.4: `codeType` (VARCHAR(50) — target `CREDIT_ID`; vocabulary legacy `TrCas`/`CreditId`/`CreditItid` konsolidasi → `CREDIT_ID` BR-33), `companyId`, `branchId`, `formatTemplate` (VARCHAR(100) — jangan seed dari literal `code_format='Branch_YYYY_MM_00001'` tanpa koreksi; aktual YY 2-digit `branch(5)+YY+MM+SEQ(5)`), `resetPeriod` (enum `NONE|MONTHLY|YEARLY`), `sequenceName` (DB sequence per scope, seed ≥ max legacy), `effectiveFrom`/`effectiveTo`, `isActive`.
3. `GlLinkService` — E36 GET (read) + PATCH (audited update, maker-checker U-009); NO delete (BR-BE07-24). CoA `[LOCKED]` zero-diff enforced via migration checksum (runtime: just store).
4. `NumberFormatService` — E38 admin CRUD `cfg_number_format`; `CREDIT_ID` code_type change → maker-checker (BR-BE07-05 — salah format memutus keunikan nasional). Internal `generateCreditId(branchId)` method (consumer BE-01 calls via API or shared service — NOT public endpoint; uses DB sequence per scope, seed ≥ max legacy, format `branch(5)+YY+MM+SEQ(5)` OQ-GT-02 ✅). Counter `last_number` TIDAK dimigrasi (DB sequence — fix DB-CONVENTIONS §6.5 manual-increment race).
5. `GlLinkController` `@RestController @RequestMapping("/gl-transaction-type-links")` — E36 GET/PATCH (maker+checker). `NumberFormatController` `@RestController @RequestMapping("/number-formats")` — E38 GET/POST/PATCH (`CREDIT_ID` change → maker+checker). Auth: Credit (Admin).
6. `GlLinkAndNumberFormatTest` — E36 no delete; E38 `CREDIT_ID` change → maker-checker; `generateCreditId` format 14-char `branch(5)+YY+MM+SEQ(5)`; CoA zero-diff `@Column`.

## Acceptance criteria

- E36 `map_transaction_type_gl`: read + audited update only; NO delete (BR-BE07-24); maker-checker WAJIB (BR-BE07-05); CoA `[LOCKED]` zero-diff `@Column`.
- E38 `cfg_number_format`: `CREDIT_ID` code_type change → maker-checker (BR-BE07-05).
- `NumberFormat.formatTemplate` NOT seeded from literal `code_format='Branch_YYYY_MM_00001'` without correction (aktual YY 2-digit — BE-07 §3.4 caveat).
- `generateCreditId(branchId)` produces 14-char `branch(5)+YY(2)+MM(2)+SEQ(5)` (OQ-GT-02 ✅); DB sequence per scope, seed ≥ max legacy.
- Counter `last_number` NOT a column (DB sequence — fix DB-CONVENTIONS §6.5 manual-increment race; `[ARTIFACT]` do-not-replicate).
- Konsolidasi 3 code_type legacy (`TrCas`/`CreditId`/`CreditItid`) → `CREDIT_ID` (BR-33 — risiko tabrakan legacy).
- `map_transaction_type_gl` key `ux_..._trx_id_class_id`.
- All tests pass.
