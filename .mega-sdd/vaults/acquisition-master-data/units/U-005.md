# Unit U-005 — Dealer master family entities + repository (Tier A)

## Goal

Implement 5 dealer-family JPA entities (`mst_dealer`, `mst_dealer_document`, `mst_dealer_personnel`, `mst_dealer_job_title`, `mst_dealer_branch_access`) per BE-07 §3.2. KTP/NPWP `[LOCKED]` zero-diff. `is_sub_dealer_enabled` flag (fix EC6 name-literal). FK parent eksplisit (fix EC7 notes-as-join-key). Deactivate-only.

## Context

- **Vault source:** `03-data-model.md §Dealer master family (Tier A)`; `constitution §I-003` (no hard delete); `06-constraints.md BR-BE07-07/08/09`
- **Binding refs:** C-03 (dealer family NEW — 6 tables; this unit 5, bank-ref U-006), OQ-DLRPTN-01 (shape live MsDealer vs MsDealer1 vs backup — census uses MsDealer candidate; backup = ARTIFACT discard)
- **Why this scope:** BE-07 §10 urutan (3) Dealer family. Entities first (U-005), bank-reference + controller (U-006). KTP/NPWP `[LOCKED]` zero-diff = migration checksum constraint. Dealer = origination 01 & PO email 04 dependency.

## Implementation steps

1. `Dealer.java` `@Entity @Table(name="mst_dealer")` extends `VersionedEntity`. Fields BE-07 §3.2: `dealerCode` (business key `ux_mst_dealer_dealer_code`), `dealerName`, `isAuthorizedDealer`, `isSellingNewProductOnly` (BR-BE07-08 carve-out), `isUsedCar`, `parentDealerCode`/`groupCode`/`mainDealerCode` (FK eksplisit bertipe — fix EC7, NOT join via `notes`), `isSubDealerEnabled` (flag — fix EC6 name-literal `'%PT Lucas Digital Indonesia%'` NOT ported), `ktpNo`/`ktpName` `[LOCKED]`, `npwpNo` `[LOCKED]`, `status` (enum active|inactive), `activationDate`/`deactivationDate`, `notes` (free-text, NOT join key). PK `id BIGINT IDENTITY`.
2. `DealerDocument.java` `@Entity @Table(name="mst_dealer_document")` — `dealerCode` FK, `docType` (enum `SIUP|TDP_NIB|NPWP|KTP|MP_MASTER_DEALER|SPT_ACCOUNT_BOOK`), `fileRef` (object storage key, NOT FTP path — fix `30-...§6` ARTIFACT), `uploadedBy`/`uploadedAt`. Key `ux_..._dealer_code_doc_type`.
3. `DealerPersonnel.java` `@Entity @Table(name="mst_dealer_personnel")` — `personnelId` (business key `ux_`), `dealerCode` FK, `name`, `jobTitleId` FK, `status` (enum `A|inactive` — BR-DLRPTN-1 eligibility), `bankReferenceId` FK nullable. BE-07 §3.2 fields.
4. `DealerJobTitle.java` `@Entity @Table(name="mst_dealer_job_title")` — `jobTitleId` (business key `ux_`), `description`, `dealerPaymentCode`, `isActive`.
5. `DealerBranchAccess.java` `@Entity @Table(name="mst_dealer_branch_access")` — `dealerCode` FK, `branchId`, `isActive`. Key `ux_..._dealer_code_branch_id`. (BR-BE07-07 branch-scoped picker).
6. Repositories: `DealerRepository`, `DealerDocumentRepository`, `DealerPersonnelRepository`, `DealerJobTitleRepository`, `DealerBranchAccessRepository` (all `JpaRepository`).
7. `DealerEntityTest` — entity mapping; `parentDealerCode` FK typed (not `notes`); `isSubDealerEnabled` boolean flag; KTP/NPWP `@Column` mapped; no DELETE (lifecycle via `status`).

## Acceptance criteria

- `Dealer.parentDealerCode`/`groupCode`/`mainDealerCode` = typed FK (fix EC7 — NOT join via `notes` free-text).
- `Dealer.isSubDealerEnabled` = boolean flag (fix EC6 — `'%PT Lucas Digital Indonesia%'` literal NOT ported).
- `Dealer.ktpNo`/`ktpName`/`npwpNo` `[LOCKED]` `@Column` mapped (zero-diff migration checksum).
- `DealerDocument.fileRef` = object storage key (NOT FTP path).
- `DealerPersonnel.status` enum `A|inactive` (BR-DLRPTN-1).
- No hard-delete path (BR-BE07-03 — `status`/`isActive` lifecycle).
- `MsDealer1`/`MsDealerBackup20221227` NOT modeled (OQ-DLRPTN-01 — ARTIFACT discard; census uses `MsDealer`).
- All tests pass.
