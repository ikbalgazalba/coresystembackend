# Unit U-001 — Master-data module scaffold + shared base classes

## Goal

Scaffold the `masterdata` sub-package under `com.coresystem.coresystembackend` with shared base classes (`AuditableEntity`, `VersionedEntity`, `PageResponse`) + `MasterDataConfig`, so all subsequent 07 units extend a consistent audit/version/pagination foundation per DB-CONVENTIONS §4 + BR-BE07-20.

## Context

- **Vault source:** `02-architecture.md §Domain module layer` (M7 trunk reference leaf, sub-package `acquisition.masterdata`); `constitution §A-002` (paket layer standar + masterdata sub-package); `06-constraints.md BR-BE07-20` (pagination standar); `docs/DB-CONVENTIONS.md §4` (audit columns wajib)
- **Binding refs:** C-09/C-10/C-11/C-12 (all endpoints use PageResponse), C-18 (lifecycle), OQ-ARCH-STACK (framework Spring Boot confirmed via scan)
- **Why this scope:** Every 07 entity needs `created_at/created_by/updated_at/updated_by` (DB-CONVENTIONS §4); master mutable user konkuren needs `version` (optimistic locking); all list endpoints need `PageResponse{items,page,total_pages,record_count}` (BR-BE07-20). Building these once prevents fan-out divergence (sibling-consistency §12.7). Spring Modulith boundary enforced later via ArchUnit (ADR-03) — package-info declares the module.

## Implementation steps

1. Create `masterdata/package-info.java` declaring the Spring Modulith module boundary (`@org.springframework.modulith.ApplicationModule`).
2. Create `masterdata/common/AuditableEntity.java` — `@MappedSuperclass` with `created_at TIMESTAMPTZ`, `created_by VARCHAR(50)`, `updated_at TIMESTAMPTZ`, `updated_by VARCHAR(50)` (DB-CONVENTIONS §4; `@PrePersist`/`@PreUpdate` not auto — set in service layer from `AuthenticatedActor`).
3. Create `masterdata/common/VersionedEntity.java` — extends `AuditableEntity`, adds `@Version Integer version` (optimistic locking for master mutable user konkuren — DB-CONVENTIONS §4).
4. Create `masterdata/common/PageResponse.java` — generic record `PageResponse<T>(List<T> items, int page, int totalPages, long recordCount)` + static `of(Page<T>, page, size)` factory (BR-BE07-20 standardized pagination).
5. Create `masterdata/config/MasterDataConfig.java` — `@Configuration` placeholder (auditing `AuditorAware<String>` bean reads from `SecurityContextHolder` → employee NIK; enable `@EnableJpaAuditing`).
6. Write `MasterDataScaffoldTest` — verify `PageResponse.of()` builds correctly; `AuditableEntity`/`VersionedEntity` annotated (`@MappedSuperclass`/`@Version`).

## Acceptance criteria

- `./mvnw compile` clean; `masterdata` package resolvable as Spring Modulith module.
- `AuditableEntity` has 4 audit columns typed per DB-CONVENTIONS §3 (`TIMESTAMPTZ`/`VARCHAR(50)`).
- `VersionedEntity` adds `@Version Integer version`.
- `PageResponse<T>` matches BR-BE07-20 shape `{items[], page, total_pages, record_count}`.
- `AuditorAware` bean resolves employee NIK from security context (placeholder OK — real auth OQ-ARCH-STACK).
- All tests pass.

- Spring Modulith ArchUnit test (ADR-12 — separate verification unit after modules land).
- Real auth wiring (OQ-ARCH-STACK; `AuditorAware` placeholder returns "SYSTEM" until auth service lands).
