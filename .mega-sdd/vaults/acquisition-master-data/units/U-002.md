# Unit U-002 — Employee mirror entity + repository + HR sync job (Tier B)

## Goal

Implement `mst_employee_mirror` (Tier B synced mirror, read-only) + `EmployeeMirrorController` (E8 picker) + `EmployeeMirrorSyncJob` (HR one-way sync, BR-EMPLOYEE-1). `is_resigned` (`Fkeluar`) WAJIB diekspos eksplisit (fix Edge Case 12 — legacy comment-out filter `IsActive`).

## Context

- **Vault source:** `03-data-model.md §Employee mirror (Tier B)`; `04-flows.md F-U-003` (E8 HR picker); `06-constraints.md BR-BE07-22` (resigned/not-found/source-error = 3 sinyal berbeda, fail=error eksplisit)
- **Binding refs:** C-02 (employee mirror NEW), C-09 (E8 endpoint), OQ-BE07-02 (HR sync mechanism/frequency — menunggu; sync job interface stub, real transport deferred)
- **Why this scope:** Prasyarat provisioning user (U-003) & PIC picker (U-008) — keduanya butuh NIK lookup + status resign eksplisit. BE-07 §10 urutan (1) HR mirror sync + E8. Tier B = read-only; write HANYA sync job (BR-EMPLOYEE-1).

## Implementation steps

1. `EmployeeMirror.java` `@Entity @Table(name="mst_employee_mirror")` extends `AuditableEntity` (no `@Version` — read-only). Fields per BE-07 §3.1: `nik` (String, `@Column(name="nik")`, `ux_mst_employee_mirror_nik`), `name`, `branchId` (`KdCabang`), `positionId` (`KdJabat`), `nationalId` (`NoKtp` VARCHAR(16) `[LOCKED]`), `isResigned` (boolean, `Fkeluar`), `employeeStatus` (`Stpegawai`), `joinDate` (`Tglmasuk`), `exitDate` (`Tglkeluar`). PK `id BIGINT IDENTITY`. `nik` = business key `ux_`.
2. `EmployeeMirrorRepository extends JpaRepository<EmployeeMirror, Long>` + `findByNik(String)` + `findByNikContainingIgnoreCaseAndIsResignedFalse(..., Pageable)`.
3. `EmployeeMirrorController` `@RestController @RequestMapping("/employees")` — E8 `GET /employees` (search: nik/name/branch/position; **status resign eksplisit** di response). Read-only. Auth: Credit (Admin) / Hierarchy Admin. Returns `PageResponse<EmployeeMirrorDto>`.
4. `EmployeeMirrorSyncJob` — `@Component` interface stub `syncFromHr()` (mekanisme transport OQ-BE07-02: batch/CDC/API — stub throws `UnsupportedOperationException("OQ-BE07-02 HR sync transport not yet decided")` until resolved; NOT auto-resolved). On sync: set `isResigned` from HR `Fkeluar`; trigger auto-deactivate users (BR-BE07-27) via event (event listener in U-003).
5. `EmployeeMirrorTest` — E8 returns resign status eksplisit; lookup not-found → `404` (not empty); `503 LOOKUP_SOURCE_UNAVAILABLE` distinct from not-found (BR-BE07-22).

## Acceptance criteria

- `EmployeeMirror` has `isResigned` boolean field (fix Edge Case 12 — NOT comment-out like legacy `vw_HREmployeeData`).
- E8 `GET /employees` returns `is_resigned` in response; filter `is_resigned=false` default.
- Not-found NIK → `404 EMPLOYEE_NOT_FOUND` (eksplisit, bukan sukses-kosong — BR-BE07-22).
- `nationalId` NIK `VARCHAR(16)` `[LOCKED]` (DB-CONVENTIONS §3).
- `EmployeeMirrorSyncJob.syncFromHr()` stub marked TBD OQ-BE07-02 (no silent fake implementation).
- `POST /employees` does NOT exist (HR system-of-record BR-EMPLOYEE-1 — TIDAK ada endpoint write).
- All tests pass.
